# ObjectFrame

Тестовый проект на C99 с JSON-подобным деревом данных и собственным бинарным форматом сериализации. Программа создаёт объект в памяти, записывает его в байтовый буфер, затем восстанавливает объект из этого буфера.

## Цели

- объекты и массивы с произвольной вложенностью;
- целые числа, числа с плавающей точкой, булевы значения, строки и `null`;
- поиск значения по ключу;
- сериализация в бинарный буфер и обратная десериализация;
- вывод размера и hex-дампа сформированного сообщения.

## Сборка

Требуются CMake 3.16 или новее и компилятор с поддержкой C99.

```powershell
cmake -S . -B build
cmake --build build --config Debug
```

Исполняемый файл называется `ObjectFrame`.

## Демонстрация

`init_jobj()` строит вложенное дерево, сериализует его в `msg_arr`, выводит размер и байты сообщения, а затем десериализует его обратно.

После восстановления пример находит элемент с `id = "350"` в массиве `Test array` и выводит его поле `alias`:

```text
Serialized message, 680 bytes:
08 01 01 76 61 6C 75 65 20 6F 6E 65 00 09 03 00
...
Deserialized alias for id 350: test/id350
```

## Основные типы

- `Value_t` описывает одно значение: его тип, ключ и данные;
- `Cmx_obj_t` представляет объект или массив значений;
- `Var_value_t` хранит данные конкретного значения.

Основные функции объявлены в `src/jobj.h`:

```c
Cmx_obj_t* make_cmxobj(Type_cmxobj type, Value_t meaning);
uint8_t add_value(Cmx_obj_t* cmx_obj, Value_t meaning);

Value_t* find_value(Cmx_obj_t* cmx_obj, const char* key);
Cmx_obj_t* find_values(Cmx_obj_t* source_obj, const char* key);

bool init_msgarr(void);
uint16_t get_msg_size(void);
void make_msg(Cmx_obj_t* cmx_obj);
Cmx_obj_t* extract_msg(uint8_t* msg);
void free_obj(Cmx_obj_t* cmx_obj);
```

## Бинарный формат

Для каждого объекта или массива записываются количество значений и его тип. Для каждого значения записываются тип, ключ объекта или пустой байт для элемента массива, затем сами данные. Ключи и строки завершаются нулевым байтом.

Целые числа и `float` копируются в буфер в представлении текущей платформы.
